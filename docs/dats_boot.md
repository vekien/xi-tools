# DATs loaded at boot / init

Files loaded during boot and initialisation, grouped by source. Each line shows
the DAT's header magic (first 4 bytes, hex + ASCII) and file size in bytes.

Header/size data: base-game ROM files from `research/ftable_full_scan.json`;
FTABLE/VTABLE index files and `ROM/0/0.DAT` read directly from the game install.
Override DATs (catseyexi, ffxi-hd) are matched by ROM path against the base-game
scan, so their header magic reflects the base file's format.
