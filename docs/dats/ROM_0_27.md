# ROM/0/27.DAT - Animation / Value Curves (`damv`)

**Path:** `ROM/0/27.DAT`  
**Size:** 4,960 bytes (`0x1360`)  
**Magic:** `damv`  

This file is not a fourth `sel_` control file. It starts with `damv` and contains compact animation
or value-curve data. The names inside include `mis2`, `dam2`, `cur2`, `dam1`, `dam0`, `cur0`, `cur1`,
`mis0`, `mis1`, plus parameter names like `m0py`, `m1rz`, `d0sx`, `d0sy`, `c0py`, `c0sx`, `c0sy`,
and `c0ca`.

Current best interpretation: `27.DAT` is an animation/value-curve table for damage, cursor, and/or
mission-related UI effects. It is more likely to drive transitions such as pop, scale, rotation, or
alpha than static title/menu placement.

## Relevance To Menu Position

`27.DAT` is more promising than expected for animated UI effects, but it does not look like the
static title/menu position owner. The values are normalized curve values around `0.0` to `2.8`, not
screen-pixel coordinates and not the `menu` element structs used by `ROM/0/1.DAT`.

If experimenting, the safest first probes are curve values in `m0py` or `c0py`, because their names
suggest Y-position curves and the values are small, localized float32 edits.
