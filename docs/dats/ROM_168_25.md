# ROM/168/25.DAT — Auto-Translate Dictionary (English)

**Path:** `ROM/168/25.DAT`
**Size:** 36,798 bytes
**Magic:** none — starts with `02 02 01 00` (the first entry's control code)

This file is the **auto-translate phrase dictionary** — the database behind the in-game
auto-translate feature (the bracketed `{Greetings}` / `{Expansions}` phrases you insert with
the Tab key). It is **not** a menu-string table and does **not** drive the mission menu.
It is documented here because it contains nation and expansion names as plain ASCII, which
makes it a common false-positive when grep-scanning for menu strings — and because it is the
authoritative source for the auto-translate phrase set if we ever localise custom content.

---

## Structure

The file is a flat sequence of **categories**, each introduced by a full-width bracketed
title and followed by its phrase entries.

### Category header

```
81 79  <ASCII name>  81 7a        ; full-width brackets 【 name 】 (Shift-JIS 0x8179 / 0x817a)
<uint32 count>  <uint32 reserved> ; entry count for this category
```

### Phrase entry

Each phrase carries its own **auto-translate insertion code** inline:

```
02 02  <cat>  <idx>   <len>   <ASCII text>  00
└──────┬──────────┘    │         │
   insertion code      │         └ null-terminated phrase text
   (4 bytes)           └ length byte = strlen + 1 (includes the null)
```

- `02 02` is the FFXI auto-translate token prefix **inside this DAT** — the 4 bytes
  `02 02 <cat> <idx>` are the dictionary record's key; the receiving client looks the pair up
  here and renders the localised text. This is why every entry stores its own code.
  **On the chat wire the tag is a different, longer form** — external byte evidence
  (2026-08 crosscheck) says 6 bytes, `0xFD`-framed; the earlier claim that the client emits
  the raw 4-byte record prefix conflated the DAT-internal key with the wire encoding.
- `<cat>` is the 1-based category number (Greetings = `0x01`, … Expansions = `0x29`).
- `<idx>` is the entry number within the category.

### Example — the `Expansions` category (`cat = 0x29`, at `0x8b94`)

02 02 29 01  13  "Rise of the Zilart"     00

## Relationship to the mission menu

None directly. The mission-menu category labels come from the `XISTRING` menu-string tables
under `ROM/97/` — see [ROM_97_menu_strings.md](ROM_97_menu_strings.md). This dictionary is a
separate system. If custom missions ever introduce new proper nouns, the matching
auto-translate phrases would be added **here** so players can reference them in chat.
