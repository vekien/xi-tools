# ROM/0/22.DAT - Japanese Player Title Strings

**Path:** `ROM/0/22.DAT`  
**Size:** 32,768 bytes (`0x8000`)  
**Magic:** none  

This file is a fixed-size Japanese string table for player titles. It is not a texture, scene, or
menu layout file.

---

## Top-Level Layout

The file contains exactly `512` fixed-size records:

```text
0x8000 / 0x40 = 512 records
```

Each record is `0x40` bytes:

```text
+0x00  uint32   title_id       little-endian; matches record index
+0x04  char[]   title_text     Shift-JIS, null-padded
+0x3F  uint8    terminator     always 0xFF
```

Confirmed invariants:

| Field | Finding |
|---|---|
| record count | `512` |
| record size | `0x40` bytes |
| `title_id` | matches record index for all records |
| final byte | `0xFF` for all records |
| text encoding | Shift-JIS |

## Editing Notes

Text edits must stay inside the fixed `0x3B` byte text area from `+0x04` through `+0x3E`.
Strings are Shift-JIS and null-padded. Do not overwrite the final `0xFF` byte at `+0x3F`.

Changing the ID field is not useful for normal text edits because every ID already matches its
record index.
